## Bariera: Pierwsze Lata — launcher 1.0.0

Pierwsze publiczne wydanie launchera serwera Bariera (G1R:MP 0.1.9).

- Instalator z wyborem folderu i skrótem na pulpicie.
- Stan serwera na żywo: brama otwarta/zamknięta, echo, liczba osób.
- Przycisk startu uruchamia oficjalny klient G1R:MP i łączy z Barierą.
- Hasło serwera zapamiętywane w formie zaszyfrowanej.
- Automatyczne aktualizacje launchera.

**Instalacja:** pobierz `Bariera-Launcher-Setup.exe`. Jeśli Windows pokaże ostrzeżenie SmartScreen, kliknij „Więcej informacji” → „Uruchom mimo to” (instalator nie jest podpisany cyfrowo).
