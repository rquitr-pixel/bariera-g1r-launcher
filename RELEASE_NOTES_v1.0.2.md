## Bariera: Pierwsze Lata — launcher 1.0.2

Poprawka błędu antycheatu „COULD NOT JOIN … (code 25): Game process exited”.

- Launcher nie wymaga już uprawnień administratora — uruchamia oficjalny launcher G1R:MP tak samo, jak robisz to ręcznie.
- Po kliknięciu „Dołącz” launcher nie wykonuje już żadnych dodatkowych kliknięć ani nie zmienia okien w czasie startu gry.
- Jeśli Gothic już działa, launcher nie startuje go drugi raz.

Jeśli Windows pokaże ostrzeżenie SmartScreen: „Więcej informacji” → „Uruchom mimo to”.
